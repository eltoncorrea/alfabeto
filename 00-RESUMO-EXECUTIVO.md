## 🚀 Início Rápido (Prioridades - TUDO GRATUITO)

### **SEMANA 1 - Google Meu Negócio (PRIORIDADE #1):**
1. Criar perfil: https://business.google.com
2. Preencher TODAS informações
3. Adicionar 10+ fotos de trabalhos
4. Solicitar verificação (cartão postal)
5. Configurar mensagens/WhatsApp
6. ✅ **Resultado: Aparecer no Google Maps e buscas locais**

### **SEMANA 1 - Landing Page:**
1. Criar conta GitHub: https://github.com/signup
2. Criar repositório público "alfabeto-sign"
3. Fazer upload do arquivo `template-landing-page.html`
4. Fazer upload da pasta `assets/` com imagens
5. Ativar GitHub Pages nas configurações
6. ✅ **Site no ar: `https://[usuario].github.io/alfabeto-sign`**

### **SEMANA 2 - Instagram:**
1. Mudar bio para versão sugerida
2. Adicionar link: wa.me/5531998558388
3. Criar 6 destaques (Stories Highlights)
4. Fazer primeiro Reel (usar CapCut - grátis)
5. Postar nos Stories (manhã, tarde, noite)
6. Engajar com 20 perfis locais diariamente
7. ✅ **Resultado: Perfil profissional e ativo**

### **SEMANA 3 - WhatsApp Business:**
1. Baixar WhatsApp Business (grátis)
2. Configurar perfil profissional
3. Criar catálogo de serviços
4. Configurar respostas rápidas
5. Começar usar Status diariamente
6. ✅ **Resultado: Atendimento profissional**

### **SEMANA 4 - Expansão:**
1. Entrar em 5-10 grupos Facebook locais
2. Começar pedir avaliações no Google
3. Fazer primeira parceria local
4. Criar rotina de posts
5. ✅ **Resultado: Presença consolidada**

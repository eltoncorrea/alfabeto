## 🛠️ Passo a Passo de Implementação

### **MÉTODO 1: GitHub Pages (Recomendado)**

#### **Passo 1: Criar conta no GitHub**
1. Acesse: https://github.com/signup
2. Crie conta gratuita com e-mail `alfabetosign@gmail.com`

#### **Passo 2: Criar repositório**
1. Clique em "New repository"
2. Nome: `alfabeto-sign`
3. Marque "Public"
4. Marque "Add a README file"
5. Clique "Create repository"

#### **Passo 3: Fazer upload dos arquivos**
1. Clique em "Add file" > "Upload files"
2. Faça upload da estrutura HTML pronta (vou criar abaixo)
3. Faça upload das imagens da pasta `assets/`

#### **Passo 4: Ativar GitHub Pages**
1. Vá em "Settings" do repositório
2. No menu lateral, clique "Pages"
3. Em "Source", selecione "main branch"
4. Clique "Save"
5. Seu site estará em: `https://[usuario].github.io/alfabeto-sign`

#### **Passo 5: Domínio personalizado (Opcional)**
- Comprar domínio barato: www.registro.br (~R$ 40/ano)
- Exemplo: `alfabetosign.com.br`
- Configurar DNS para apontar para GitHub Pages

## 📱 Otimizações Importantes

### **SEO Básico:**
- Título da página: "Alfabeto Sign - Comunicação Visual em Ipatinga | ACM e Letreiros"
- Meta description: "Especialistas em comunicação visual, placas em ACM, adesivos e letreiros em Ipatinga, Coronel Fabriciano e Timóteo. Orçamento grátis!"
- Meta keywords: "comunicação visual ipatinga, ACM ipatinga, letreiros ipatinga, adesivos ipatinga, placas ipatinga"

### **Performance:**
- Comprimir imagens antes do upload (usar tinypng.com)
- Tamanho ideal: máximo 200KB por imagem
- Formato: JPG para fotos, PNG para logo

### **Mobile-First:**
- Layout responsivo (adapta a celular)
- Botões grandes e fáceis de clicar
- WhatsApp clicável em mobile

### **Conversão:**
- Botão WhatsApp fixo no canto da tela
- Múltiplos pontos de contato
- Call-to-action claros
